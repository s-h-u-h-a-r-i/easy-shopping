# UI Component Roadmap — easy-shopping

Track which components are built, in progress, or pending.

## High Priority (Core Shopping Experience)

| Component | Status | Notes |
|-----------|--------|-------|
| **Button** | ✅ Done | 4 variants (primary, secondary, ghost, destructive), 3 sizes, icons, loading state |
| **Input** | ✅ Done | Label, hint, error states, icons, full-width option |
| **Checkbox** | ✅ Done | For marking items checked/unchecked in shopping lists |
| **Card** | ⬜ Pending | Shopping lists, products, groups in grid layout |
| **Dialog/Modal** | ⬜ Pending | Confirmations (delete, remove member), quick-add items, create lists |
| **Badge/Tag** | ⬜ Pending | List status (active/shopping/completed), categories, user roles |
| **IconButton** | ⬜ Pending | Compact actions: edit, delete, more options |

## Medium Priority (Navigation & Layout)

| Component | Status | Notes |
|-----------|--------|-------|
| **Tabs** | ⬜ Pending | Switch between "Active", "Shopping", "Completed" list states |
| **Sheet/Drawer** | ⬜ Pending | Mobile slide-out menus for nav and filters |
| **Avatar** | ⬜ Pending | User profiles in group member lists |
| **ListItem** | ⬜ Pending | Shopping list row: checkbox + name + quantity + actions |
| **AppBar/Header** | ⬜ Pending | Top navigation with back button, title, actions |
| **BottomNav** | ⬜ Pending | Mobile tab bar for main sections |

## Lower Priority (Enhanced UX)

| Component | Status | Notes |
|-----------|--------|-------|
| **Toast** | ⬜ Pending | Notifications: "Item added", "List shared", errors |
| **Select/Dropdown** | ⬜ Pending | Choose groups, categories, status filters |
| **Search/Autocomplete** | ⬜ Pending | Product lookup by name or barcode |
| **Skeleton** | ⬜ Pending | Loading placeholders while data fetches |
| **EmptyState** | ⬜ Pending | Illustrations when no lists/items exist |
| **FloatingActionButton** | ⬜ Pending | Primary action button on mobile lists |
| **Menu** | ⬜ Pending | Context menus for more actions |
| **Tooltip** | ⬜ Pending | Explain icon buttons, show full text on truncate |
| **Divider** | ⬜ Pending | Visual separation between list sections |
| **Spinner/Loader** | ⬜ Pending | Full-page or inline loading states |
| **Progress** | ⬜ Pending | Show completion % of shopping list |
| **Switch/Toggle** | ⬜ Pending | Settings toggles (dark mode, notifications) |
| **Stepper** | ⬜ Pending | Multi-step flows (invite wizard, onboarding) |
| **Accordion** | ⬜ Pending | Expandable sections in settings/help |

## Status Legend

- ✅ **Done** — Built, tested, documented in demo page
- 🚧 **In Progress** — Currently being implemented
- ⬜ **Pending** — Not yet started
- 📝 **Planned** — Needs design/spec before building
